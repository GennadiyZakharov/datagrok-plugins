# Param Reference

The example of parameter referencing in Datagrok
The goal of the example – show the capability of referencing one of parameter values from another parameter
This capability was described in Datagrok docs only for SQL queries:
https://datagrok.ai/help/datagrok/concepts/functions/func-params-annotation#referencing-other-parameters

This pachage provides a set of example demonstrating Parameter referencing in JS/TS fucntions.
